# mvrhaa.github.io

Interactive branch graph of my public and pinned GitHub repositories, one branch per language.
Click a branch or a language to see the repositories written in it.

The data comes from [`data/repos.json`](https://github.com/mvrhaa/mvrhaa/blob/main/data/repos.json) in my profile repository,
which a GitHub Actions job regenerates from the GitHub API every 15 minutes, so new public repositories show up on their own.

Font: [Figtree](https://github.com/erikdkennedy/figtree), SIL Open Font License 1.1 (`fonts/OFL.txt`).
